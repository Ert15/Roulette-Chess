# ♟🔫 Roulette Chess

Шахматы с русской рулеткой! После каждого хода фигура крутит барабан — 1/3 шанс смерти.

## Правила

- Стандартные шахматные ходы
- **Король ♔ и Ферзь ♛** — иммунитет, рулетка не применяется
- **Все остальные фигуры** — после хода крутят барабан (1/3 шанс умереть)
- Игра заканчивается когда сучается мат или пат
