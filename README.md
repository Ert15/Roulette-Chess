# ♟🔫 Roulette Chess

Шахматы с русской рулеткой! После каждого хода фигура крутит барабан — 1/6 шанс смерти.

## Правила

- Стандартные шахматные ходы
- **Король ♔ и Ферзь ♛** — иммунитет, рулетка не применяется
- **Все остальные фигуры** — после хода крутят барабан (1/6 шанс умереть)
- Игра заканчивается когда Король умирает от рулетки или взят

## Структура проекта

```
lib/
├── main.dart                        # Точка входа
├── models/
│   ├── piece.dart                   # Фигуры (тип, цвет, символ)
│   ├── position.dart                # Позиция на доске
│   ├── chess_rules.dart             # Логика ходов
│   └── log_entry.dart               # Запись в журнале
├── providers/
│   └── game_state.dart              # Состояние игры (ChangeNotifier)
├── screens/
│   └── game_screen.dart             # Главный экран
└── widgets/
    ├── board_widget.dart            # Доска
    ├── roulette_widget.dart         # Анимация рулетки
    ├── move_log_widget.dart         # Журнал ходов
    └── captured_pieces_widget.dart  # Захваченные фигуры
```

## Запуск

```bash
# Запустить
flutter run

# Собрать APK (Android)
flutter build apk --release

# Собрать для iOS
flutter build ios --release

# Запустить в браузере
flutter run -d chrome
```
